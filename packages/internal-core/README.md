# @arcenpay/internal-core

Private shared runtime package for ArcenPay internal builds.

Do not install this package directly unless you are working on ArcenPay-owned
integrations. For customer-facing usage, install one of:

```bash
npm install @arcenpay/react
```

```bash
npm install @arcenpay/node
```

Production app origin defaults to `https://app.arcenpay.com`.
